# wine-quality-prediction
Machine learning models for predicting wine quality using Python and scikit-learn.

## Overview
A machine learning project to predict wine quality based on chemical properties.

## Objectives
- Explore the dataset
- Analyze feature relationships
- Build predictive models
- Compare model performance

## Methods
- Exploratory Data Analysis
- Linear Regression
- Random Forest
- Model evaluation

## Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Results
Compared Linear Regression and Random Forest models for wine quality prediction. Random Forest achieved the best performance, with an R² of 0.539 and an MSE of 0.301, outperforming Linear Regression (R² = 0.403, MSE = 0.390).
## How to run
1. Clone the repository
2. Install the required packages
3. Open `wine_quality_prediction.ipynb`
4. Run the notebook cells
